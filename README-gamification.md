# Gamification

This version adds a persistent gamification layer on top of the existing habit tracker.

## Features
- XP for completing habits
- Level progression
- Daily quests
- Achievement badges
- XP history
- Streak and best-streak summary
- Level-up / achievement feedback on the dashboard
- Dedicated `/gamification` page and navigation item

The existing habit, log, AI, analytics, authentication and SQLite features remain intact.
